One substrate

Cells, crystals, light curves, survey respondents. Same object.

Every verse keeps its data on AnnData. Observations, annotations, descriptors and results travel together, and write to h5ad / zarr — no new file format, no lost rows when you merge, filter or featurise twice.

.X measurements
.obs cells · materials · sources · units
.var genes · elements · bands · items
.obsm embeddings · structures · light curves
.uns provenance · run records

Capability lives in the library, not in the prompt.

Agents are already good at reading papers and writing code. What they lack is a trusted, queryable toolbox for each science. That is what we build.

01

Registered for lookup

Every public function is registered with what it does and what it needs, so an agent asks before it writes code.

02

Tested against a reference

Each function is checked against an independent implementation or known result — not just that it runs.

03

Executed in a tutorial

Every function appears in a tutorial that actually runs, so usage is shown, not described.

04

Grown from failures

When an agent fails a held-out research task, the missing method goes into the library — and is tested on tasks it has never seen.
